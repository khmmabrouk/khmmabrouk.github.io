PUBLISH FOR FREE WITH GITHUB PAGES
1. Create or sign into https://github.com/ and choose a username.
2. Create a public repository named YOURUSERNAME.github.io (replace YOURUSERNAME with your actual username).
3. Upload index.html and khaled-mabrouk.jpeg directly to the repository root using Add file > Upload files, then commit.
4. In Settings > Pages, choose Deploy from a branch, main, /(root), and Save.
5. Visit https://YOURUSERNAME.github.io/ once deployment completes.
6. Add the published URL to ORCID and LinkedIn. Register the URL-prefix property in Google Search Console and follow its verification instructions; request indexing with URL Inspection.
7. After publishing, replace the relative og:image and JSON-LD image URLs in index.html with the full public image URL, and optionally add a canonical link using the actual homepage URL. Never use a guessed URL.
Review the content and dates before publishing. No personal phone, residential address or full CV is included. The Watermark portfolio is linked but its contents could not be inspected.
